# Fonts

`share-tech-mono-latin.woff2` — Share Tech Mono, by Carrois Apostrophe.
Licensed under the SIL Open Font License 1.1; the full text is in `OFL.txt`,
which must stay with the font. Fetched from Google Fonts (Latin subset only,
13.5 KB) and committed here rather than hotlinked, so the demo keeps working
without a CDN.

Used by the Cipher profile for every Western character. Half-width katakana are
not in this font and come from whatever Japanese face the reader's system has;
Cipher measures for that at mount and falls back to Latin and digits alone if
there is none.

**Not** the typeface from the film. That one is a proprietary custom design by
Simon Whiteley and is not shipped here, nor is any recreation of it.
